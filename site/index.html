/ 04 — Questions

Things you'd ask
on the call anyway.

What does “proactive” actually mean?
Lumi doesn’t wait for a prompt. The background watcher tracks app hangs, memory pressure, disk health, and boot/resume issues, and acts before you notice — trims working sets, flags stuck installers, runs post-resume sweeps, catches unsaved data before a crash. You set the rules; Lumi runs the loop.
Where does the AI brain run?
Inside the Lumi control window. The brain routes prompts across multiple providers with streaming responses, runs a local Claude Code CLI integration, and supports OAuth-based Claude sessions. Chats, projects, skills, and attachments persist between sessions on your machine.
What can Lumi do with my files?
Drop a file anywhere on screen and Lumi catches it. The Markitdown worker converts Office and PDF docs into clean markdown for the AI; the OpenClaw local gateway searches, routes, and surfaces files; a document viewer opens whatever you drop in. Files never leave the device unless you tell Lumi to send them.
How does Lumi sign in?
A single browser handoff — no passwords to retype, no embedded server. The default browser opens, you sign in once, the token comes back to Lumi, and that’s the last time you think about it.
Can I extend it?
Hermes ships a bundled Python interpreter for custom adapters and HTTP-based plugins. OpenClaw is the local agentic gateway that exposes tools Lumi can call on your machine. The Skills store layers on top — new capabilities without a rebuild.
How do subscriptions work?
Personal and Pro are month-to-month, with a 14-day trial on Pro. Annual is 20% off. Team is per-seat with 5 seats included. Cancel any time. Auto-update with rollback comes bundled; opt-out telemetry feeds a per-device card on the admin side.
Where are you based?
Irvine, California — UTC-8. We work async with users in every time zone. 24-hour response on Pro, 4-hour on Team.
